- Agent-status glyph shapes, settings fields, `session.status --shape`, read-back, and tests.
- Workspace focus sets, filter state, persistence migration, control commands, and tests.
- `keymap.list`, arrow chords, keyboard-layout resolution, and close-session reload behavior.

These changes remain in `agtermCore`, shared resources, and shared documentation exactly where upstream
owns them.
Linux work is limited to GTK adapters and Linux packaging/integration surfaces.

### GTK parity work

- Replace the single focused-workspace presentation with the marked workspace set and applied/suspended
  filter.
- Expose Focus, Add to Focus, and filter toggle in GTK context menus, palette, sidebar footer, keymap,
  persistence read-back, and control dispatch.
- Implement GTK control picker presentation, keyboard/mouse selection, custom values, cancellation,
  result retention, focus restoration, and control routing.
- Render and configure agent-status shapes in the GTK sidebar, attention surfaces, dashboard chips, and
  Preferences.
- Include the OpenCode plugin in Linux integration status, preview, installation, repair, and ownership
  protection.
- Make GTK key dispatch accept upstream arrow chords and provide Linux `keymap.list` read-back.
- Implement Linux window minimize/read-back and `window new --minimized`.
- Verify OSC 111 resets the Linux per-pane transparency overlay.
- Update Linux CI and release ancestry pins to `v0.19.0`.

### Platform-specific adaptations and exemptions

- The macOS Dock menu has no portable GTK/freedesktop equivalent and remains macOS-only.
- macOS Reduce Transparency and Reduce Motion observers are AppKit accessibility APIs.
  GTK follows toolkit and desktop accessibility behavior where exposed and does not emulate AppKit
  notifications.
- GTK4 does not expose reliable restorable x/y placement.
  Linux continues to omit window geometry while supporting resize, maximize, fullscreen, and minimize.
- Linux notification and status sounds continue to map to the desktop bell because `GNotification` has no
  portable sound catalog.
- The GTK palette already maintains stable rows during keyboard navigation.
  The AppKit-specific palette flicker fix requires no Linux code.
