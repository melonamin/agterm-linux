## Deliberate platform exemptions

- macOS TCC/Finder/Dock/Homebrew/DMG/signing/notarization and AppKit/SwiftUI implementation details remain upstream-only.
- Linux uses GTK/libadwaita controls, desktop notifications, Ctrl/Shift labels, and compositor-owned window placement.
- Metal-specific hidden-surface mechanics are not copied. GTK naturally stops drawing unmapped stack pages;
  libghostty occlusion remains deferred until its OpenGL renderer can reliably rebuild on remap.
- macOS login-shell wording does not apply. Linux Live mode uses the platform-supported zmx build and documents its
  own shell/runtime requirements.
