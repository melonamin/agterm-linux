# Linux v0.24.0 catch-up

## Range

- Previous Linux parity base: upstream `v0.22.0`
  (`8192f0ba48ebd3d716f77c8a02c8bec06535e708`)
- Target parity base: upstream `v0.24.0`
  (`834b74a7f78de06e1c4f66c5e24eafccd047ec64`)
- Integration branch: `agent/upstream-v0.24.0-sync`, based on `origin/linux-port`
- Merge commit: `20eb336` (`chore(linux): merge upstream v0.24.0`)
- Excluded range: the 21 commits on `upstream/master` after `v0.24.0`

The release is an exact tagged catch-up.
Post-tag upstream work must not be included implicitly.

## Inventory

### Portable core and shared artifacts

- Horizontal and vertical split axes, persisted axis state, split aliases, and Close Split.
- Keymap alternatives separated by `|`, including built-in leader alternatives and deterministic override
  collision handling.
- Previous/next workspace navigation and per-workspace collapse toggling.
- Overlay-aware session copy and text capture.
- Surface cursor-column control read-back.
- Exclusive control-socket ownership and clearer unrealized-surface failures.
- Shared command protocol, CLI behavior, tests, cookbook recipes, plugin metadata, and bundled skill docs.
- Quit-reason policy and newer libghostty integration requirements.

Shared behavior remains in `agtermCore` only when it is host-free and upstream-compatible.
Linux work is limited to portable corrections, GTK adapters, the Linux control server/CLI, packaging, and
platform documentation.

### GTK and Linux adapter work

- Keep `QuitReason` host-free on Linux while preserving its AppKit entry point on macOS.
- Render top/bottom and left/right splits with the matching GTK orientation, persist/read back the axis,
  and close the secondary pane with correct teardown and focus restoration.
- Dispatch alternative key chords and the new workspace navigation/collapse actions through GTK.
- Add workspace navigation/collapse to the palette and relevant GTK menus.
- Route overlay copy/text to the covering terminal surface and reject unsupported overlay kinds clearly.
- Return cursor-column read-back from the selected Linux terminal surface.
- Enforce exclusive Linux control-socket ownership without unlinking another live instance's socket.
- Update the Linux libghostty revision and Zig line, reapply the Linux bridge patches, and verify rendering,
  resize, input, teardown, and lifecycle behavior.
- Keep the Linux CLI, bundled agent skill, docs, CI ancestry checks, staging, and release metadata aligned
  with the implemented surfaces.

### Platform-specific adaptations and exemptions

- The v0.24.0 system-wide Quick Terminal hotkey is macOS-specific in this release.
  Linux keeps its existing in-window Quick Terminal and app-local shortcut because GTK/Wayland has no
  portable compositor-wide registration mechanism.
  The maintainer approved this explicit product exception on 2026-08-21.
- AppKit panel behavior, Dock menus, Apple Events, TCC audio usage strings, entitlements, `os.Logger`, and
  macOS wake observers remain macOS-only.
- Linux must still accept and describe the shared `global-hotkey` keymap verb without claiming that it
  registers a compositor-wide shortcut.
- GTK follows the desktop's realization and wake behavior rather than copying AppKit's display-wake retry
  mechanics verbatim.
