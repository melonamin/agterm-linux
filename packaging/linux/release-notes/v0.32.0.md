### Linux adaptations

- Bring the GTK4/libadwaita frontend and shared control protocol through upstream 0.32.0, including native asks, cross-window attention, hooks, custom-command failure HUDs, markdown HUDs, per-pane backgrounds, and expanded control and keymap coverage.
- Bundle zmx v0.8.1 with the explicit leadership patch. Remote sessions exchange status, context, notifications, HUDs, asks, overlays, and split-layout changes through the presentation stream. A covered local pane remains scriptable through its zmx daemon.
- Keep the Linux terminal and child-process lifecycle on the GLib main loop, including remote presentation, overlay jobs, ask handback, and pane reattachment. Honor a static Ghostty title without losing zmx role reports.
- Verify the GTK control paths with isolated real app instances, a patched zmx daemon, and SSH-style attachment. Build and verify the x86_64 tar, DEB, RPM, and AppImage payloads locally.

Linux keeps Quick Terminal in-window and does not register the macOS global hotkey. The macOS `remote-image-paste` cookbook recipe is not advertised for Linux until a Linux clipboard transport is implemented. macOS signing, notarization, Homebrew, and TCC flows remain upstream-only.
