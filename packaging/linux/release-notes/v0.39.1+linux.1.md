### Maintenance fixes

- Preserve the screen and scrollback of Live commands held open with `--wait` after they exit.
  Managed zmx clients now clean up terminal modes without erasing the command's final output.
  This preserves output that reaches the pane; it does not add retention for commands that finish before attachment.
- Give remote program overlays the terminfo database bundled beside the remote CLI when `TERM=xterm-ghostty`
  and `TERMINFO` is absent or empty.
  Existing `TERMINFO` values and other terminal types are preserved.
- Raise the Linux control socket backlog to the system maximum for bursts of concurrent clients.
- Resolve palette and picker Ctrl-J/K navigation through the shared keyboard-layout mapping.
  Extra modifiers no longer trigger that navigation.
- Apply control-picker prompts through GTK's search-entry API so placeholder text appears correctly.
- Finish app-controlled Ghostty resource environment and process-locale initialization before GTK starts worker threads.

### Verification and compatibility

- Add Linux GUI/control regression coverage for held Live command output, startup initialization order,
  remote-overlay terminfo, and palette/picker navigation on a Russian keyboard layout.
  The isolated GTK suite gates branch and release CI.
- Verify the remote-overlay terminfo path over real OpenSSH with an installed CLI directory layout.
- Keep the exact upstream v0.39.1 base with the existing companion identity correction and the narrow
  upstream terminfo and Live-output backports.
- Live sessions require zsh or fish as the login shell, with the bundled shell integration.
  Package compatibility remains x86_64 with GTK4, libadwaita, and WebKitGTK 6.0 on the host.
  DEB and RPM require Python 3; tar installs require it on the host for Codex hook JSON parsing.
  AppImage remains unavailable until WebKit helper processes can be bundled reliably.
