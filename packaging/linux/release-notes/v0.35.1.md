### Linux adaptations

- Catch up from upstream v0.33.1 to stable v0.35.1, including the shared terminal model, control protocol, CLI, and agent integrations.
  Commits after v0.35.1 are excluded.
- Add native GTK coverage for Live pane restart, preserving pane identity and ending the old foreground program without changing the selected session.
  Stable pane IDs also route typing, text reads, and cursor queries to the owning pane and window.
- Extend WebKitGTK overlays with the file-page command bridge, opt-in JavaScript requests, submitted values and outcomes, chromeless panels, page reload, and zoom.
  Persistent URL overlays share browser storage within the active state directory; `browser clear` refuses while a persistent page remains open.
- Retain the last screen while remote panes reconnect, expose retry reason and count, and support reconnecting remote presentations.
  Wire network and wake notifications through Linux adapters.
- Support repeatable keymap leaders, Ctrl+j/k navigation in palettes and pickers, the new-session placement preference, `keymap run`, and detached-daemon `zmx screen` reads.
- Detect OpenCode v1/v2 in the user's login-shell environment and offer a native choice when its version is unknown.
  Preserve existing configuration and managed entrypoints, including offline installs.
- Apply the upstream zmx/Ghostty blank-cell formatter fix to the pinned Linux runtime and include its nested patches in cache validation.
  Preserve demand-driven rendering and reapply stored split ratios when the available pane area changes.

### Verification and compatibility

- Shared core: 4,025 tests in 175 suites passed.
  Linux: 553 tests in 81 suites passed.
  Strict lint, Debug and Release/WMO builds, core-boundary checks, CLI sharing, resource checks, and runtime-cache validation passed.
- All 49 isolated GTK smoke scenarios passed under X11/Xvfb.
  Focused checks exercised real HTML storage and command routing, held and cross-window leaders, foreground-process cleanup, background pane restart, actual SSH-255 disconnect/retry, and remote-presentation reconnection.
- Physical suspend/resume, native network-monitor transitions, and a real Wayland compositor were not exercised.
  Native callbacks compile; ordinary pane and presentation retries were verified at runtime.
- Live sessions require zsh as the login shell.
  Quick Terminal remains inside the Linux window; the older-zmx Live Session reset remains unsupported.
- Packages remain x86_64 tar.gz, DEB, and RPM with a host WebKitGTK 6.0 dependency.
  AppImage remains omitted until WebKit helper processes can be bundled reliably.
  macOS signing, notarization, Homebrew, and AppKit behavior belong to upstream.
