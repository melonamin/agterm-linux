### New features

- **HTML pages in overlays.** `session overlay open --html FILE` and `--url URL` show generated reports, documentation, or a running development server in a full, floating, or split-pane overlay.
  The source bar includes Close; `--navigation` adds history, reload, and browser actions.
  `session overlay reload` and `session overlay navigate` expose those actions to scripts, while `tree` reports the current page and load state.
  Page JavaScript is disabled unless `--js` is passed, and a local file can read assets only within the directory granted by `--cwd`.
  Opening an external browser from page content requires confirmation.
  [#659](https://github.com/umputun/agterm/pull/659)

### Improvements

- Remote sessions show a cloud glyph and their host in Ctrl-Tab, recent-session, and attention rows.
  [#650](https://github.com/umputun/agterm/pull/650)
- The HTML navigation bar can reveal the current local file in the file manager or copy a web page's current URL.
  The `session overlay navigate finder` command reveals a file from a script; `tree` supplies the URL for scripts.
  [#663](https://github.com/umputun/agterm/pull/663)
- The new `html-doc-overlay` cookbook recipe generates a static HTML explainer and opens it in an overlay.
  [#662](https://github.com/umputun/agterm/pull/662)

### Fixes

- An overlay or ask stays on its origin when that host leads the target pane, even if a remote viewer still presents the session.
  [#661](https://github.com/umputun/agterm/pull/661)
- The Claude status hook counts a non-`exec` launcher and its Claude child as one agent, so the pane's own status is no longer suppressed.
  Reinstall the hook to receive the update.
  [#651](https://github.com/umputun/agterm/pull/651)
- A remote pane wrapper survives Ghostty's `exec` behavior and reports the SSH process's exit instead of going blank.
  [#654](https://github.com/umputun/agterm/pull/654)
- The `two-agent-chat` recipe recognizes newer Codex CLI composer layouts, including a right-aligned footer notice.
  [#656](https://github.com/umputun/agterm/pull/656)
