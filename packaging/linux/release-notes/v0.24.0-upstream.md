### New Features

- Quick Terminal is a floating macOS panel with a system-wide `global-hotkey` keymap verb. #441 @umputun
- Keyboard navigation between workspaces adds `previous_workspace`, `next_workspace`,
  `workspace.go --to next|prev`, and `toggle_workspace_collapse`. #436 @umputun
- `session.overlay.copy` and `session.overlay.text` read an overlay's own surface. #437 @umputun
- `surface.cursor` reports a surface's cursor column. #451 @umputun

### Improved

- libghostty advances to upstream main, fixes a surface-teardown crash, and now builds with Zig 0.16.
  #449 @umputun
- A cookbook recipe reports hook-driven agent status from inside a container. #428 @nquo

### Bug Fixes

- Keymap chord collisions resolve deterministically instead of depending on file order. #444 @umputun
