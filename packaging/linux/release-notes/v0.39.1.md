### Linux adaptations

- Track exact upstream v0.39.1, including the accumulated v0.35.1 through v0.39.1 changes.
  Later upstream features are excluded; the companion identity correction is narrowly backported.
- Add nested companion sessions, disclosure and reveal, duplication, page companions, and parent-shell respawn.
  Local and remote companions share the upstream lifecycle and control protocol.
- Add session and workspace tints, flagged layouts and ordering, membership editors, Recent control commands, undoable close, and lifecycle events.
  The GTK actions, keybindings, palettes, and control read-back use the shared model.
- Extend WebKitGTK presentations with remote pages and streamed assets, bridge requests and outcomes, hidden overlays, point-based sizing, link-opening modes, and browser overrides.
  Bind page resource grants to the owning WebView so another open page cannot reuse them.
- Add native text, multiline, radio, checkbox, and Other forms, including pane forms above full-session overlays.
  Support sticky and frameless HUDs, wrapped content, and modifier-clicked links.
  Keep ask panels opaque and centered, bound pane widths and long choices, and outline multiline inputs.
  Preserve replacement palette input, hide floating pages and programs, and route HUD links across split dividers.
  Exclude Linux resource metadata from the theme catalog and support newer GLib flag imports.
  Fit rasterized text watermarks to their bitmap so wide and multiline labels remain complete.
- Add Attach Remote and live remote-configuration observation, foreground-program restart, Live fish shells, reconnect replay, and the newer keymap and picker behavior.
- Route deferred pane-focus work through the GTK main loop and carry upstream terminal teardown fixes in the pinned Linux runtimes.
  Release the IBus input context with its terminal and unbind unrealized widgets, preventing a crash when deleting a focused workspace.
  Duplicated companion programs use their own session/pane identities, including IDs embedded in arguments.
  Align sidebar parent/peer rows and indent companions without changing row heights.
  Own SSH stream children and their waiters directly so a live OpenSSH process cannot block Foundation's process watcher or retain its own input pipe.

### Verification and compatibility

- Shared core: 4,795 tests in 214 suites passed.
  Linux package: 563 tests in 85 suites passed.
  Strict lint, Debug and Release/WMO builds, host-free boundaries, CLI sharing, architecture, resources, and runtime-cache checks passed locally.
- The full 58-scenario isolated GTK suite gates branch and release CI under X11/Xvfb.
  Real IBus workspace deletion and keyboard input are covered, along with GUI/control companion identity rebinding.
  Rendered checks covered light/dark forms and overlay visibility at normal and doubled scale, plus small windows and large interface fonts.
  Focused runtime checks covered HTML storage and bridges, page resource isolation, overlay forms, remote reconnection and ask handback, and real OpenSSH loopback pages, companions, and parent respawn.
- Physical GPU rendering, compositor placement, cross-host network latency, physical suspend/resume, and native network-monitor transitions remain outside the automated suite.
- Live sessions require zsh or fish as the login shell, with its bundled integration.
  Quick Terminal remains inside the Linux window; the older-zmx Live Session reset remains unsupported.
  Keyboard input-source selection and global shortcut registration retain the documented compositor constraints.
- Packages are x86_64 tar.gz, DEB, and RPM with a host WebKitGTK 6.0 dependency.
  DEB and RPM now require Python 3 for Codex hook JSON parsing; tar installs need Python 3 on the host.
  DEB installs also require the SVG image loader so toolbar and sidebar icons render on minimal systems.
  Package verification preserves the literal tilde in prerelease version metadata.
  AppImage remains omitted until WebKit helper processes can be bundled reliably.
  The one-line ask field uses GTK styling; AppKit styling, macOS signing, notarization, and Homebrew packaging belong to upstream.
