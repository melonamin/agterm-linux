### Fixes and improvements

- **Ctrl-Tab switching:** cycling works from terminal search and sidebar rename fields, keeps the highlighted row visible, and follows the current theme.
  Releasing the last Ctrl key commits once, including the GTK modifier-state race found during verification.
  Zoom, Dashboard, dialogs, and popovers own the keyboard while open; Esc or window deactivation cancels a cycle.
  [#45](https://github.com/melonamin/agterm-linux/pull/45)
- **Theme changes with many sessions:** changing a theme no longer deadlocks the app's terminal mailbox.
  Existing surfaces update their foreground colors immediately, and program-set backgrounds survive theme changes.
  Clearing a session background returns to the theme when no program background override is active.
  Native checks cover 16 and 24 sessions, preview/cancel, paired light/dark themes, and terminal color queries.
  [#46](https://github.com/melonamin/agterm-linux/pull/46)
- **Live and remote sessions:** clean-quit command capture follows the selected restore mode, and replay follows the decision made at launch.
  Follower-pane takeover keeps app shortcuts working and suppresses the takeover key and its repeats; releasing that key in search or an auxiliary window no longer swallows the next press.
  Ask rejection preserves unrelated overlays, stale exits cannot close replacement surfaces, and delayed clipboard reads skip surfaces that have been destroyed.
  Remote rows use consistent connection glyphs, local launches choose local working directories, and zmx attach validation and kill confirmations are handled correctly.
  [#47](https://github.com/melonamin/agterm-linux/pull/47)

### Verification and compatibility

- Independent Astra and Fable reviews completed, with confirmed defects fixed and reviewed again.
- Shared-core tests, Linux app tests, Debug and Release builds, lint, boundary checks, and native GTK scenarios pass.
  Remote checks use two real app processes connected over OpenSSH loopback.
- Native automated verification uses X11/Xvfb; a real Wayland compositor and cross-host network latency were not covered.
  The separate overnight desktop freeze report remains unproven; this revision fixes the reproduced theme-triggered deadlock.
- Live sessions require zsh as the login shell.
  Quick Terminal remains inside the Linux window, and the older-zmx Live Session reset remains unsupported.
- Packages remain tar.gz, DEB, and RPM with a host WebKitGTK 6.0 dependency.
  AppImage remains omitted until WebKit helper processes can be bundled reliably.
