### New Features

- **Explicit pane lead for attached sessions.** A remote attach claims the lead in every pane, so the panes take the attaching host's size at once. A pane that does not lead is covered, and a keypress or `agtermctl session lead` takes the lead back. When the leader goes away the pane reattaches by itself. `surfaces[].lead` in `tree` reads the role back. On the host where a covered pane runs, `session type`, `session text`, and `surface cursor` keep working through zmx; commands that act only on the local surface refuse there. Both hosts need 0.32.0, and a Live session still running an older zmx keeps the old behavior until it is recreated. [#635](https://github.com/umputun/agterm/pull/635)
- **Attached hosts follow the origin's split layout.** The origin publishes split layout on the presentation stream. An attached host applies the axis, hide and show, and swap to panes it already has, and closes a pane the origin removed. A split opened on the origin after attach appears on the next attach. Local panes, divider ratio, and keyboard focus stay local. [#636](https://github.com/umputun/agterm/pull/636)
- **Title-bar context mirrored to attached hosts.** An attached session shows the origin's `session context`. A context set on the attached row overrides it, and `session context --clear` there restores the origin's latest value. [#634](https://github.com/umputun/agterm/pull/634)
- **Markdown HUD.** `session hud open --markdown` renders headings, emphasis, lists, code blocks, quotes, rules, and tables, with a 4096-character cap instead of plain text's 256. `--font-size PT` sets the panel's font size at open. An update must repeat `--markdown` or the panel returns to plain text. `--file FILE` reads the message from a file, and the tree's `hud` node reads back `markdown` and a requested `fontSize`. [#641](https://github.com/umputun/agterm/pull/641)
- **Per-pane session background.** `session background image|text|color|clear` accepts `--pane left|right|scratch`. Each pane of a split can carry its own tint or watermark over the session default. Left and right overrides follow their terminal through swaps and relaunch; a scratch override ends when that terminal closes. `tree` reports `paneBackgrounds` next to `background`. [#647](https://github.com/umputun/agterm/pull/647)
