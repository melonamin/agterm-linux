### Linux adaptations

- Add WebKitGTK 6.0 rendering for local HTML and URL overlays in the GTK frontend, with a native navigation bar, Show in Files action, theme variables, load-state readback, and the same control commands as macOS.
- Keep the WebKit view alive when an overlay changes size or moves between panes, and close its network session when the overlay ends.
- Block file and URI-list drops or paste into embedded pages; URI-list link drags are also blocked.
- Mark attached sessions with a cloud glyph and host in the GTK switcher and session popovers.
- Carry the remote pane-wrapper and Claude status-hook fixes into the Linux package.
- Keep sidebar inline renaming readable and stable in size across themes.
- Keep terminal zoom surfaces in place so they continue rendering, with correct overlay visibility, split ratios, titles, and focus when switching zoom targets.
- Verify full, floating, pane, local-file, and HTTP pages through the real GTK app and control socket, including a granted script and a blocked cross-origin redirect.
- Ship tar, DEB, and RPM packages with a host WebKitGTK 6.0 dependency. The AppImage is omitted until its separate WebKit helper processes can be bundled reliably.

Linux keeps Quick Terminal inside its window and has no macOS global hotkey.
The older-zmx Live Session reset remains unavailable on Linux; `zmx.reset` returns unsupported.
macOS signing, notarization, Finder, Homebrew, and TCC flows remain upstream-only.
